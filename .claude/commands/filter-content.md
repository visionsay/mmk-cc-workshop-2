# 시황 분석 콘텐츠 필터링

YouTube 영상 목록에서 시황 분석 관련 콘텐츠만 필터링합니다.

## 실행 절차

1. `config.json`을 읽어 필터 설정을 확인합니다:
   - **포함 키워드**: 시황, 시장분석, 장마감, 마감시황, 증시전망, 장전시황, 미국시황, 주간전망, 데일리, 마켓, 인사이트, 여의도
   - **제외 키워드**: 크립토, 비트코인, 이더리움, 코인, NFT

2. 입력으로 받은 영상 목록(또는 /check-youtube 결과)에서:
   - 영상 제목에 **포함 키워드** 중 하나 이상이 포함된 영상을 선택합니다.
   - 영상 제목에 **제외 키워드**가 포함된 영상은 제외합니다.

3. 필터링된 영상 목록을 다음 형식으로 출력합니다:

```
## 시황 분석 콘텐츠 (N건)
1. [채널명] 제목 | URL | 게시일 | 매칭 키워드: xxx
2. ...
```

4. 필터링 결과가 없으면 "시황 분석 관련 새 영상이 없습니다."를 출력합니다.

## 필터링 규칙
- 제목 매칭은 대소문자 구분 없이 수행합니다.
- 포함 키워드가 하나라도 매칭되면 후보로 선정합니다.
- 제외 키워드가 하나라도 매칭되면 후보에서 제거합니다.
- 제외 키워드가 포함 키워드보다 우선합니다.

## 인자
이 스킬은 영상 목록을 인자로 받거나, /check-youtube 결과를 직접 참조할 수 있습니다.
