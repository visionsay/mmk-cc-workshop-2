# YouTube 영상 자막 추출 및 요약

YouTube 영상의 자막을 추출하고 핵심 내용을 한국어로 요약합니다.

## 인자
- `$ARGUMENTS`: YouTube 영상 URL (예: https://www.youtube.com/watch?v=VIDEO_ID)

## 실행 절차

1. 전달받은 YouTube URL로 `mmk youtube transcript` 명령을 실행하여 자막을 추출합니다:
   ```bash
   mmk youtube transcript <youtube-url>
   ```

2. 자막이 정상적으로 추출되면, 다음 구조로 요약합니다:

### 요약 형식

```
## 📊 [영상 제목]

### 핵심 요약 (3~5문장)
- 오늘 시장의 전반적인 흐름과 주요 이슈를 요약

### 주요 포인트
1. **[주제1]**: 설명
2. **[주제2]**: 설명
3. **[주제3]**: 설명

### 언급된 종목/섹터
- 종목명 또는 섹터 (언급된 경우에만)

### 전망/시사점
- 향후 전망이나 투자 시사점 요약
```

3. 자막이 없거나 추출 실패 시:
   - `mmk youtube metadata <youtube-url>` 명령으로 메타데이터를 가져와 제목과 설명만으로 간략히 요약합니다.

## 요약 지침
- 한국어로 작성합니다.
- 전문 용어는 그대로 사용하되, 핵심을 놓치지 않도록 합니다.
- 투자 판단에 도움이 되는 핵심 정보를 우선적으로 추출합니다.
- 요약은 간결하되 주요 수치와 데이터는 보존합니다.
- 요약 전체는 500자 이내로 유지합니다.

## 주의사항
- `mmk youtube transcript` 명령은 YouTube URL만 지원합니다.
- Shorts 영상은 자막이 짧을 수 있으므로 메타데이터도 함께 참고합니다.
- 자막 추출이 실패하면 에러를 보고하고 메타데이터 기반 요약으로 대체합니다.
